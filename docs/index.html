Study Design

Counterbalancing & Randomization

Condition assignment: Each participant is randomly assigned to one of 5 between-subjects conditions (Verbatim, Non-Verbatim, Enhanced, Bullet Points, or SpeechSpectrum Demo). The condition determines how transcripts are presented throughout the entire session.

Transcript order: All participants see all 3 transcripts (A, B, C) in a randomized order (Fisher-Yates shuffle). This is a within-subjects factor — every participant evaluates every transcript.

Question order: Multiple-choice questions are reshuffled for each transcript. Free-response questions always appear at the end. Question order is logged per transcript.

What gets logged: Condition assignment, transcript order, question order, per-question timing, per-transcript timing, total session time, style switch events with timing (demo condition), highlighted text per question with style attribution, all survey responses, and demographic data.
